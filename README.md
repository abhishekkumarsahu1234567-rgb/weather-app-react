# 🌤 Weather App (React + Material UI)

A modern weather application built using **React.js** and **Material UI** that allows users to search for real-time weather data of any city.

---

## 🚀 Features

* 🔍 Search weather by city name
* 🌡 Displays temperature, min/max temp, humidity
* 🌥 Shows weather condition (haze, clear, etc.)
* 🎨 Clean and responsive UI using Material UI
* ⚡ Fast API integration using OpenWeather API

---

## 🛠 Tech Stack

* React.js
* Material UI (MUI)
* JavaScript (ES6+)
* OpenWeather API
* CSS

---

## 📦 Installation

```bash
npm install
npm run dev
```

---

## 🔑 API Used

* OpenWeather API
* Endpoint:

```
https://api.openweathermap.org/data/2.5/weather
```
